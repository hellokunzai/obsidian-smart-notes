## 联网搜索秘钥按钮 + 测试按钮 bug 修复
- **反显/保存 bug**：`renderWebTab` 中 `selectKeyBtn` 点击处理闭包引用了渲染时的 `const currentWebKey`，保存后该值陈旧，再次打开弹窗会预选初始值（第一个），确认时覆盖掉新选择。修复：点击时改调 `this.getCurrentWebKey(prov)` 实时读取。
- **测试按钮永远成功 bug**：`WebSearchService.testConnection` 返回 `results.length >= 0`（恒真），且各 provider 的 `search` 在 HTTP 非 200 时 `continue`/`return []` 吞掉错误。修复：provider 在 HTTP≠200 / 响应含 `error` 字段 / 网络异常时记录并最后 `throw lastErr`；`testConnection` 不再吞掉错误，向上传播；公共 `search()` 加 try/catch 仍返回 `[]` 保持轮询行为。新增 i18n `settings.test.httpError`。
