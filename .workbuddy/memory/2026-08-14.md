# 2026-08-14

## Bug 修复：秘钥选择器「添加密钥」按钮无反应
- 根因：`styles.css` 中 `.ana-secret-picker-add-form { display: none }` 默认隐藏，而 `SecretPickerModal.showAddSecret()` 用 `this.addFormEl.style.display = ""` 清空内联样式后回退到 CSS 的 `none`，表单永远不显示。
- 修复：`showAddSecret()` 改为 `style.display = "flex"`（覆盖 CSS），`hideAddForm()` 仍用 `display="none"`。
- 顺带修复 `modelLinkModal.ts:519` 的 i18n key 拼写错误：`settings.modelLists.modal...` → `settings.modelLinks.modal...`。
- 版本 0.10.0 → 0.10.1（patch）。仅改源码与元数据，未 git 提交（死命令）。

## 提示项（待用户决策，未执行）
- `SecretStorage` API 要求 Obsidian ≥ 1.11.4，但 `manifest.json` 的 `minAppVersion` 仍为 1.4.0。在 1.4.0 上运行会调用不存在 API 而崩溃。需用户决定是否提升 minAppVersion（会影响低版本用户安装）。
