## 角色信息弹窗保存后跳回模型配置页 — 修复
- **问题**：在「会话与记忆」tab 的角色弹窗中点击「添加」保存后，设置页重绘并固定 `activate(0)`，跳回「模型配置」tab
- **根因**：`AiNoteAgentSettingTab.display()` 每次重绘都调用 `activate(0)`；弹窗保存后回调 `this.display()` 触发整页刷新，默认回到第一个 tab
- **修复**：
  1. 在 `AiNoteAgentSettingTab` 中新增 `private activeTabIndex = 0`，记录当前选中 tab 索引
  2. `display()` 开头保存 `previousActiveIndex = this.activeTabIndex`
  3. `activate(idx)` 中同步更新 `this.activeTabIndex = idx`
  4. 渲染完所有 section 后调用 `activate(previousActiveIndex)`，保持当前 tab
- **涉及文件**：`src/settings.ts`
- **验证**：`npm run build` 通过

## Skill 启用开关不持久化 — 修复
- **问题**：设置页「Skill 技能」列表中，单个 skill 的启用 toggle 打开后重启/重进设置页会失效，但关闭时能保存
- **根因**：`renderSkillsTab()` 中 toggle 的 `onChange` 处理启用分支时，只 `arr.push(sk.path)` 修改了临时数组，未把 `arr` 写回 `plugin.settings.defaultSkills`，导致 `saveSettings()` 存的是旧数组
- **修复**：重写 toggle 的 onChange，确保任何状态变更后都执行 `plugin.settings.defaultSkills = arr` 再 `saveSettings()`
- **涉及文件**：`src/settings.ts`
- **验证**：`npm run build` 通过
