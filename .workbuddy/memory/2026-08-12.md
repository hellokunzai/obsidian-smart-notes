## ai-note-agent 插件：多会话（会话历史侧栏）改造

基于 0.2.0 的记忆能力继续升级，把单一会话改造成多会话管理：

- **存储层重写**（`src/utils/aiFolder.ts`）：`chat-history.json` 从裸数组升级为多会话结构 `{version, activeSessionId, sessions[]}`，定义 `Session/SessionMessage/SessionsFile` 类型；新增 `loadSessions/saveSessions/createSession`，旧版裸数组自动迁移为单个「已导入的对话」会话。注意 `crypto.randomUUID()` 在浏览器环境可用（Obsidian 桌面端支持）。
- **聊天视图重写**（`src/view/chatView.ts`）：左侧新增可折叠会话历史侧栏（`≡` 折叠）；支持新对话(`+`)、切换任意会话、重命名(`✎` Modal)、删除(`🗑` 二次确认 Modal)；首条助手回复后自动用首句 user 消息前 30 字命名（仅在仍为默认标题时）；「清空当前」只清消息保留会话。多选沿用 `Modal/Setting/ButtonComponent`。
- i18n 新增 zh/en key：`toggleSidebar/newSession/history/noSessions/defaultTitle/renameSession/sessionTitle/deleteSession/confirmDelete/sessionsLoaded/clearCurrent`；旧 `view.clear` 保留用于按钮文案之外的场景（实际 header 用 `clearCurrent`）。
- `styles.css` 新增侧栏布局、会话列表项 hover 操作、折叠态、弹窗按钮样式。
- 版本号 0.2.0 → 0.3.0（manifest/package/versions 同步）；README 补充 Multiple sessions 段落；`npm run build` 通过（main.js 88.4kb），安全扫描无禁用 API。
