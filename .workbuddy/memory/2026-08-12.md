**症状**：用户反复反馈「样式改了不生效」（聚焦高亮去不掉、图标调大看不出变化）。

**正确发布流程**：`npm run build` 后，必须把 `styles.css`（以及 main.js）复制到上面这个目录，再在 Obsidian 里重新加载插件（Ctrl/Cmd+R 或 设置→社区插件 关闭/开启）才能看到样式变化。注意：源码 `D:\WorkSprace\gitee\ai-note-agent\` 与 vault 目录是两份独立文件，不是软链。

**教训**：凡是只改 styles.css 的需求，改完务必同步文件并提示用户重载插件；不要只靠 build。本轮已用 `cp` 把最新 styles.css 拷到 vault 并 `diff` 确认一致。

## 目录重命名：VaultMind（本轮）

用户要求把「项目目录 + 插件目录」都从 ai-note-agent 改名为 vault-mind。

### 结果
- **插件目录**：✅ 成功改名 `D:\WorkSprace\obsidian\obsidian_vault\.obsidian\plugins\ai-note-agent` → `.../plugins/vault-mind`（mv 同盘原子操作，data.json 等全部保留）。
- **项目目录**：❌ 被 OS 拦截，未能从 agent 内完成。

### 根因（重要经验）
- agent 的持久 bash（pid 观察为 1475）被 harness 每轮命令强制 `cd` 回 workspace 目录（即 `D:\WorkSprace\gitee\ai-note-agent`），该进程把目录当成自己的工作目录。
- Windows 不允许重命名「任何进程当前所在的目录」（EBUSY / Device or resource busy）。Git Bash `mv`、PowerShell `Move-Item`、独立进程均失败；文件级改名成功（证明非外部程序锁文件，纯 cwd 占用）。
- `cmd /c move` 被安全策略拦（禁止从 Bash 调 cmd.exe）。
