# 2026-08-12

## AI Note Agent 插件：知识库索引 + 显式文件/文件夹附加（v0.3.0 → v0.4.0）

按 obsidian-plugin-dev 阶段流程完成开发，已通过 tsc 构建、安全扫描、i18n 校验、版本同步。

### 需求
- AI 能看到知识库所有文件（仅路径索引，不读内容），但对话中默认不加载任何文件内容。
- 只有用户显式附加文件/文件夹，或在消息中点名某文件时，才读取其内容与上下文。
- 聊天框上方新增「附件栏 + 从知识库选择文件/文件夹」入口。

### 关键设计决策（用户确认）
- 仅显式附加：移除旧的「自动附带当前活跃笔记」逻辑（删 getNoteContext/getActiveNote）。
- 附件按会话独立保存（Session.attachments: {type:file|folder, path}[]）。
- 索引仅含 Markdown 文件。

### 改动文件
- src/utils/aiFolder.ts：Session 加 attachments 字段 + 迁移兼容。
- src/context/knowledge.ts（新增）：buildKnowledgeIndex（系统提示注入路径目录）、buildAttachmentContext（解析附件→递归读内容→拼接上下文块，单文件截断、消息点名匹配）。预留 skill/web 扩展点。
- src/view/chatView.ts：附件栏 UI + AttachmentPickerModal 选择器；发送调用附件上下文；buildSystem 注入索引；彻底移除自动附带当前笔记。
- src/settings.ts：新增 includeVaultIndex（默认 true）、chatContextMaxChars（默认 8000）。
- i18n en/zh：附件栏、选择器、索引设置文案。
- styles.css：附件栏/chips/选择器弹窗样式。
- 版本 0.4.0（manifest/package/versions 三文件同步）。
