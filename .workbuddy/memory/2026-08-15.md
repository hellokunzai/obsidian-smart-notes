## Bugfix：角色列表头像列缺下划线
- 现象：设置页角色列表「头像」列整列没有横向分隔线（border-bottom），而名称/操作列有。
- 根因：`renderAvatar` 直接把传入的 `container` 变成圆形头像（addClass `.ana-avatar` + `border-radius:50%` + `overflow:hidden` + `display:inline-flex`）。在列表里 `container` 就是 `<td>` 本身，导致 `<td>` 被改造成圆形、overflow 裁掉了自身 border-bottom。
- 修复：`src/settings.ts` 在头像 `<td>` 内再套一层 `div.ana-role-list-avatar`，把 `renderAvatar` 作用在内部 div 上；`<td>` 保持正常表格单元格，分隔线恢复。其余调用点（编辑弹窗预览 / 角色 pill / 选择器行）传入的 container 本就不是 `<td>`，不受影响。
- 经验：`renderAvatar` 会改变容器自身样式，传入 `<td>` 类「既当单元格又当头像」会破坏表格边框；务必用内层 wrapper 隔离。`npm run build` 通过。
