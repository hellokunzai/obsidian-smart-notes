# Smart Notes（智能笔记）

一款 [Obsidian](https://obsidian.md) 插件，把你的仓库变成由 AI 辅助的知识工作台：和笔记对话、让 AI 按需检索你的笔记、优化笔记、在编辑器内自动补全、生成属性——全部由你配置的模型提供方驱动。

> 显示名：**Smart Notes** · 插件 ID：`smart-notes` · 需要 Obsidian 1.11.4 及以上

## 功能特性

### AI 对话面板
固定在右侧栏的对话面板，可针对你的仓库或当前笔记提问。
- **多会话**——新建、切换、重命名、删除对话；可折叠/展开历史侧栏。每个会话独立保存自己的消息、附件、skill、所选属性与联网开关状态。
- **批量操作**——在会话列表中进入批量模式，多选会话（全选 / 取消全选）后一次性删除。
- **流式回复**——实时渲染 Markdown、显示"思考中"动画、可中途停止，并在每条回复后展示 **Token 消耗**。
- **逐会话选择模型与角色**——每次对话可单独选择模型（按链接分组）与角色，仅作用于当前会话。
- **推理过程展示**——对推理模型（如 DeepSeek-R1、OpenAI o1），模型思考过程会以可折叠块显示在回复上方（设置中可开关）。
- **活动超时**——流式响应中连续多少秒未收到任何数据即判定为超时；推理模型思考时间长时可调大。另有一条固定的 10 分钟总超时兜底。
- **历史消息窗口**——较早的对话会被压缩为摘要，避免长对话撑爆 Token 预算。

### 模型配置（多提供方）
可配置一个或多个 **模型链接**，每个链接指向一个 AI 后端：
- **OpenAI 兼容**（OpenAI、Azure OpenAI、DeepSeek、本地网关等）——填写 Base URL + API Key。
- **Ollama（本地）**——仅填 Base URL，模型本地运行即完全离线。
- 每个链接可配置 **多个模型**，并可单独设置 **最大 Token / 温度**。
- API Key 保存在 **Obsidian 钥匙串（SecretStorage）**，而非明文插件数据；密钥选择器支持搜索、新建、查看与删除。提供 **测试连接** 按钮，保存前即可验证链接。
- 可把任一链接设为 **默认**，所有 AI 功能都使用该默认链接；链接列表支持按名称搜索。

### 角色（Roles）
定义可复用的 **系统提示词角色**（名称 + 提示词，可带头像）。默认角色会注入到 *所有* AI 功能（对话、优化、自动提示、属性生成）的系统提示词中；在对话中还能逐会话切换角色。它取代了旧版的单一"自定义指令"字段。

### 知识库与按需检索
插件设计上确保 AI 只看到你**主动分享**的内容，并且是**按需检索**你的仓库，而不是一次性全部载入：
- **文件索引**（可选）——开启后，AI 可调用 `search_vault_paths` 按路径/文件名关键词查找笔记，每个命中结果都 **附带该文件正文**。
- **属性索引**（可选）——AI 可调用 `search_vault_frontmatter` 按 YAML 属性（tags、category、summary 等）查找笔记，命中结果包含元数据 **与文件正文**。
- **正文搜索**——`search_vault_content` 可按正文内容查找笔记，返回命中片段。
- **按需读取**——`read_vault_notes` 可按精确路径读取一个或多个笔记的完整正文，用于读取超出结果上限或被截断的内容。
- **属性选择**（可选）——「选择属性」按钮可为当前对话挑选要注入的 Frontmatter 属性，临时覆盖全局白名单。
- **附件**——把指定文件或整个文件夹附加到对话，仅这些文件的内容会被读取。
- **@ 点名**——若在消息中提及某个库内文件名，该文件内容会被自动拉取。
- 其余内容一律留在本地：AI 未检索或读取过的笔记，正文永远不会被发送。附件与搜索命中的正文各自按可配置的字符上限截断（「文件」与「属性」两个分组的上限相互独立）。

### 技能（Skills）
把技能包（含 `SKILL.md` 的文件夹）放进 AI 文件夹的 `skills/` 目录即可；也可 **上传从 skill 市场下载的 `.zip` 包** 由插件自动解压。技能支持搜索、删除（连同其资源一并移入系统回收站）、针对新对话默认开启，也能在对话中通过 **Skill** 按钮逐会话管理。

插件会把技能以 **索引** 形式（名称 + 路径 + 一句话描述）提供给 AI，AI 可通过在回复中写入 `@use-skill: <path>` 声明调用某个技能，插件随即加载该技能的完整指令并自动继续。只有 **启用中** 的技能内容会被发送；未启用的技能仅以名称列出，让 AI 知道其存在并可建议开启。

### 联网搜索
对话内可选的联网搜索（🌐 按钮，逐会话）。支持 **Tavily / Serper（Google）/ Brave / SearXNG**，并支持多密钥轮询（一个失效自动尝试下一个）。结果可用 `[n]` 内联引用。默认关闭，仅当你在某次对话中显式开启时才调用外部 API。

### 笔记优化
**优化当前笔记** 命令让 AI 润色措辞、重组结构或撰写摘要。在差异式弹窗（原文 vs 优化后）中预览，一键应用。可配置内部链接格式（`[[wikilink]]` 与 `[markdown](path.md)`）与路径风格（最短 / 相对 / 绝对）。

### 属性生成
**生成属性** 命令读取当前笔记，让 AI 产出 YAML 前置元数据块。模版为 **每行一个字段**（也支持逗号分隔），只会生成列出的字段；其中 `date` 字段（若存在）会强制为今天。

### 编辑器内自动补全
- **实时自动提示**（可选，默认关闭）——输入时按防抖触发行内"幽灵文本"建议，按 `Tab` 接受。
- **光标处自动提示** 命令——按需触发一次建议。

### 对话记忆与长期画像
- 所有对话会话都持久化在仓库中，重启后依然保留。
- 后台会把你的对话历史提炼为 **长期画像记忆**（`memory/MEMORY.md` + 当日笔记），按可配置维度（职业、技术栈、偏好等）整理。可选择 **对话时更新** 或 **启动时更新**，也可点击 **立即整理** 手动触发。结果作为背景上下文注入，且 **完全可由用户手动编辑**。

### 多语言
界面完全国际化，跟随你的 Obsidian 语言（`设置 → 关于 → 语言`）。已内置 **English** 与 **简体中文**。新增语言：复制 `src/i18n/locales/en.json`，翻译其值，并在 `src/i18n/index.ts` 中注册即可。

## 隐私与网络使用

本插件会向你配置的端点发起 **网络请求**：
- 你所选的 **模型链接**（OpenAI 兼容或 Ollama）——笔记文本会发往你设置的 `chat/completions` 接口。
- 可选的 **联网搜索** 提供方（Tavily / Serper / Brave / SearXNG）——仅在你于对话中开启联网搜索时调用。

除你显式配置的端点外，不会向任何地方发送数据。**无遥测**。API Key 存于 Obsidian 钥匙串，而非明文插件数据。仓库文件 *内容* 仅在 AI 检索/读取某篇笔记、你附加文件/文件夹、或在消息中提及文件名时才会上传。

## AI 文件夹结构

插件加载时会在仓库根目录（文件夹名可配置，默认 `.smartnotes`）自动创建如下结构：

```
.smartnotes/
├── sessions/
│   ├── index.json            # 会话索引（仅元数据：id、标题、时间、消息数）
│   └── session-<id>.json     # 单个对话的完整内容（消息、附件、技能、所选属性、联网开关）
├── memory/
│   ├── MEMORY.md             # 长期画像记忆（自动整理、可编辑）
│   └── yyyy-mm-dd.md         # 当日记忆笔记
└── skills/
    └── README.md            # 本目录说明
```

- **索引** 仅保存轻量元数据；启动时会完整加载最近 10 个会话，更早的在你点开时才懒加载。
- 每个 **会话文件** 仅在该会话发生变化时重写。
- AI 文件夹是隐藏（以 `.` 开头）目录，因此其内容不会被仓库搜索工具检索到。

## 安装（开发）

1. 把构建产物 `main.js`、`manifest.json`、`styles.css` 复制到 `<测试仓库>/.obsidian/plugins/smart-notes/`。
2. 在 Obsidian 设置中启用插件。
3. 配置一个模型链接（设置 → Smart Notes → 模型配置）并填入 API Key / Ollama 地址。

> 开发时请使用 **独立的测试仓库**，不要在主仓库上运行本插件。
