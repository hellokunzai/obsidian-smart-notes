# Smart Notes（智能笔记）

一款 [Obsidian](https://obsidian.md) 插件，把你的仓库变成由 AI 辅助的知识工作台：和笔记对话、优化笔记、在编辑器内自动补全，并让 AI 以结构化方式认识你的仓库——全部由你配置的模型提供方驱动。

> 显示名：**Smart Notes** · 插件 ID：`smart-notes` · 需要 Obsidian 1.11.4 及以上

## 功能特性

### AI 对话面板
固定在右侧栏的对话面板，可针对你的仓库或当前笔记提问。
- **多会话**——新建、切换、重命名、删除对话；可折叠/展开历史侧栏。每个会话独立保存自己的消息、附件、Skill 与联网开关状态。
- **流式回复**——实时渲染 Markdown、显示"思考中"动画，并在每条回复后展示 **Token 消耗**。
- **逐会话选择模型与角色**——每次对话可单独选择模型（按链接分组）与角色，仅作用于当前会话。
- **推理过程展示**——对推理模型（如 DeepSeek-R1、OpenAI o1），模型思考过程会以可折叠块显示在回复上方（设置中可开关）。
- **历史窗口**——较早的对话会被压缩为摘要，避免长对话撑爆 Token 预算。

### 模型配置（多提供方）
可配置一个或多个 **模型链接**，每个链接指向一个 AI 后端：
- **OpenAI 兼容**（OpenAI、Azure OpenAI、DeepSeek、本地网关等）——填写 Base URL + API Key。
- **Ollama（本地）**——仅填 Base URL，模型本地运行即完全离线。
- 每个链接可配置 **多个模型**，并可单独设置 **最大 Token / 温度**。
- API Key 保存在 **Obsidian 钥匙串（SecretStorage）**，而非明文插件数据。提供 **测试连接** 按钮，保存前即可验证链接。
- 可把任一链接设为 **默认**，所有 AI 功能都使用该默认链接。

### 角色（Roles）
定义可复用的 **系统提示词角色**（名称 + 提示词，可带头像）。默认角色会注入到 *所有* AI 功能（对话、优化、自动提示、Frontmatter）的系统提示词中；在对话中还能逐会话切换角色。它取代了旧版的单一"自定义指令"字段。

### 知识库与隐私模型
插件设计上确保 AI 只看到你**主动分享**的内容：
- **文件路径索引**（可选）——把全部 Markdown 文件路径注入系统提示词，让 AI 知道库里有哪些文件，但不加载任何正文。
- **Frontmatter 索引**（可选）——把每个笔记的 YAML 属性（tags、category、summary 等）注入系统提示词，让 AI 理解仓库结构，同样不含正文。
- **附件**——把指定文件或整个文件夹附加到对话，仅这些文件的内容会被读取。
- **@ 点名**——若在消息中提及某个库内文件名，该文件内容会被自动拉取。
- 其余内容一律留在本地。你还可以完全隐藏"附加文件/文件夹"按钮。

### 技能（Skills）
把技能包（含 `SKILL.md` 的文件夹）放进 AI 文件夹的 `skills/` 目录即可。技能可针对新对话默认开启，也能在对话中通过 **Skill** 按钮逐会话管理。只有 **启用中** 的技能内容会被发送给 AI；未启用的技能仅以名称列出，让 AI 知道其存在并可建议开启。

### 联网搜索
对话内可选的联网搜索（🌐 按钮，逐会话）。支持 **Tavily / Serper（Google）/ Brave / SearXNG**，并支持多密钥轮询（一个失效自动尝试下一个）。结果可用 `[n]` 内联引用。默认关闭，仅当你在某次对话中显式开启时才调用外部 API。

### 笔记优化
**优化当前笔记** 命令让 AI 润色措辞、重组结构或撰写摘要。在差异式弹窗（原文 vs 优化后）中预览，一键应用。可配置内部链接格式（`[[wikilink]]` 与 `[markdown](path.md)`）与路径风格（最短 / 相对 / 绝对）。

### Frontmatter 生成
**生成 Frontmatter** 命令读取当前笔记，让 AI 产出 YAML Frontmatter 块（标题、日期、标签、分类、摘要、关键词等）。可自定义模板覆盖默认系统提示词。

### 编辑器内自动补全
- **实时自动提示**（可选，默认关闭）——输入时按防抖触发行内"幽灵文本"建议，按 `Tab` 接受。
- **光标处自动提示** 命令——按需触发一次建议。

### 对话记忆与长期画像
- 所有对话会话都持久化在仓库中，重启后依然保留。
- 后台会把你的对话历史提炼为 **长期画像记忆**（`memory/MEMORY.md` + 当日笔记），按可配置维度（职业、技术栈、偏好等）整理，作为背景上下文注入，且 **完全可由用户手动编辑**。

### 多语言
界面完全国际化，跟随你的 Obsidian 语言（`设置 → 关于 → 语言`）。已内置 **English** 与 **简体中文**。新增语言：复制 `src/i18n/locales/en.json`，翻译其值，并在 `src/i18n/index.ts` 中注册即可。

## 隐私与网络使用

本插件会向你配置的端点发起 **网络请求**：
- 你所选的 **模型链接**（OpenAI 兼容或 Ollama）——笔记文本会发往你设置的 `chat/completions` 接口。
- 可选的 **联网搜索** 提供方（Tavily / Serper / Brave / SearXNG）——仅在你于对话中开启联网搜索时调用。

除你显式配置的端点外，不会向任何地方发送数据。**无遥测**。API Key 存于 Obsidian 钥匙串，而非明文插件数据。仓库文件 *内容* 仅在你附加文件/文件夹或在消息中提及文件名时才会上传；各类索引仅携带路径/元数据。

## AI 文件夹结构

插件加载时会在仓库根目录（文件夹名可配置，默认 `.smartnotes`）自动创建如下结构：

```
.smartnotes/
├── sessions/
│   ├── index.json            # 会话索引（仅元数据：id、标题、时间、消息数）
│   └── session-<id>.json     # 单个对话的完整内容（消息、附件、技能、联网开关）
├── memory/
│   ├── MEMORY.md             # 长期画像记忆（自动整理、可编辑）
│   └── yyyy-mm-dd.md         # 当日记忆笔记
└── skills/
    └── README.md            # 本目录说明
```

- **索引** 仅保存轻量元数据；启动时会完整加载最近 10 个会话，更早的在你点开时才懒加载。
- 每个 **会话文件** 仅在该会话发生变化时重写。

## 安装（开发）

1. 把构建产物 `main.js`、`manifest.json`、`styles.css` 复制到 `<测试仓库>/.obsidian/plugins/smart-notes/`。
2. 在 Obsidian 设置中启用插件。
3. 配置一个模型链接（设置 → Smart Notes → 模型配置）并填入 API Key / Ollama 地址。

> 开发时请使用 **独立的测试仓库**，不要在主仓库上运行本插件。
